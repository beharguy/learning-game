- `npm run build` הסתיים בהצלחה; פלט סטטי עצמאי נוצר ב־`dist`.

- פרחים נשמרו לאחר רענון. רענון באמצע סיבוב מציג התחלה מחדש ואינו מוחק הישגים קודמים.
