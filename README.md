# השכונה של עלמה

משחק עברית לכיתה א׳ בדפדפן הטאבלט: עלמה מבקרת בשכונה איזומטרית, פוגשת שש דמויות ומשחקת לפי סדר החוברת ״קסם וחברים 2״, עמודים 4–79.

**[פתיחת המשחק](https://beharguy.github.io/learning-game/)** · [קוד המקור](https://github.com/beharguy/learning-game)

מסך כניסה עם עלמה מוביל למפת השכונה. נוגעים בדמות כדי להתחיל מיד. הרקעים והדמויות מבוססים על העיצובים שאושרו; הכיתוב המנוקד, האפשרויות והתגובות הם רכיבים חיים במשחק.

המפה מותאמת לכיוון הטאבלט: שתי עמודות ושלוש שורות לאורך, ושלוש עמודות ושתי שורות לרוחב. כל שש התחנות גלויות, וסיבוב המסך שומר על המשחק וההתקדמות. שורת ההוראה במפה מאפשרת גם לשמוע אותה שוב.

בסך הכול **865 משימות**. אלו משימות ותבניות עם וריאציות, לא 865 מילים שונות. בכל סבב שש משימות; בסיומו אפשר לשחק שוב או לבקר חבר אחר.

- המשימות והתשובות מתערבבות. משימה אינה חוזרת עד שממצים את המאגר הזמין ברמת הקושי הנוכחית, למעט חזרה לשאלה שנשמרה באמצע סבב.
- ברירת המחדל פותחת את כל החוברת, עם קושי הדרגתי בכל משחק. אחרי 8 הצלחות עצמאיות נוספת רמה 2, ואחרי 24 נוספת רמה 3. זו התאמת תרגול פשוטה, לא אבחון קריאה.
- ההורה יכול להגביל לעמוד מסוים או לבחור את כל הרמות. תמיד אפשר לחזור לחומר קודם. משחק שאין לו תוכן בעמוד הנבחר נשאר סגור.
- ההוראות מנוסחות ללא פנייה בזכר או בנקבה ומוקראות בקול הילה, בקצב שאושר. דוגמאות הלימוד שומרות על זכר ונקבה בהתאם לדמות. כפתורי הקראה, עזרה והדגמת נגיעה זמינים. טקסט המיועד לפענוח אינו נקרא אוטומטית, אלא דרך עזרה.
- אין שעון עצר, הפסד או ענישה על טעות. ניסיון נוסף ועזרה נרשמים בנפרד מהצלחה עצמאית.
- ההתקדמות, היסטוריית ההגרלה והשאלה הפעילה נשמרות בדפדפן. רענון חוזר לשאלה שלא הושלמה; סידור התשובות יכול להשתנות.

## הפעלה ובדיקות

דרוש Node.js 20 ומעלה. אין צורך בשרת יישומים, בסיס נתונים או מפתח API.

```sh
npm ci
npm run dev
```

כתובת הפיתוח היא `http://localhost:4173`. לבנייה ובדיקה:

```sh
npm run build
npm test
npm run preview
```

`build` יוצר `dist/` עם כל האיורים, הגופנים ו־867 קטעי MP3, ו־Service Worker לשימוש ללא רשת. בנוסף נשמרות 55 כתובות אודיו מגרסאות קודמות, המשמיעות את הקריינות המתוקנת כדי שמשחק שכבר פתוח ימשיך להשמיע קול לאחר עדכון. גודל הגרסה כ־23MB. בפתיחה הראשונה דרוש חיבור לרשת עד שהגדרות ההורים מציגות שהמשחק מוכן ללא חיבור.

בדיקות דפדפן מבודדות דורשות Chrome מותקן:

```sh
PORT=4178 npm run dev
# במסוף נוסף
npm run test:browser
npm run test:auto-advance
npm run test:map
npm run build
node scripts/qa-release.mjs
npm run test:audio-update
```

בדיקת התצוגה מכסה ארבעה גדלי מסך ואת כל ששת המשחקים. בדיקת הפריסה מפעילה שרת זמני תחת `/learning-game/`, משלימה סבבים, בודקת גיבוי ושחזור, ומנתקת את הרשת לבדיקת המשחק וההקראה מהמטמון. צילומי מסך ודוחות נשמרים ב־`docs/screenshots/neighborhood/` ואינם נשלחים למאגר.

אחרי תשובה נכונה ממתינים לסיום כל קטעי החיזוק וההסבר, ומתקדמים אוטומטית לאחר הפוגה קצרה. אין כפתור ״הבא״. ללא קול החגיגה מוצגת למשך כשנייה וחצי. בדיקת המעבר האוטומטי בודקת אירועי סיום של ניגון אמיתי בכל ששת המשחקים, השמעה חוזרת, השתקה, חסימת ניגון, מעבר לרקע ויציאה למשחק אחר. האצת הניגון בבדיקות בלבד אינה משנה את הקצב במשחק.

בדיקת המפה מכסה שמונה גדלים, לחיצה על הדמויות ועל סמלי המשחק, שמות וכפתורים שאינם מוסתרים, וסיבוב המסך ללא אובדן התקדמות. בדיקת הפריסה כוללת גם טעינת המפה האנכית לראשונה ללא רשת.

בדיקת עדכון הקול דורשת את היסטוריית Git המקומית: היא בונה את גרסת `2921db3` בתיקייה זמנית, משאירה אותה פתוחה ומחליפה את הפריסה ב־`dist` הנוכחי. נבדקים ניגון בפועל בכל ששת המשחקים לפני ואחרי רענון, שמירת ההתקדמות וכל כתובות האודיו הישנות ללא חיבור לרשת.

## פריסה והוספה למסך הבית

כל דחיפה לענף `main` מפעילה את [תהליך GitHub Pages](https://github.com/beharguy/learning-game/actions/workflows/pages.yml): בנייה, בדיקות ופרסום `dist/` בכתובת הקבועה. אין צורך להעלות את תיקיית `dist` למאגר.

בטאבלט Android פותחים את הקישור ב־Chrome, גוללים בתפריט ⋮ ובוחרים **״התקנה ויצירת קיצור דרך״** או **״הוספה למסך הבית״**. ב־iPad משתמשים בשיתוף של Safari ואז ״הוספה למסך הבית״. עדכון מוריד את כל הנכסים מחדש לפני הפעלת המטמון החדש, בלי למחוק התקדמות. הוא מופיע ברענון או בפתיחה הבאה; אין רענון כפוי באמצע משחק.

## הגדרות הורה ושמירה

גלגל ההגדרות במפה ובכניסה פותח תרגיל 7+5. זהו מחסום מפני שינוי מקרי, לא אימות אבטחה. באזור ההורים ניתן לשנות עמוד ורמה, להשתיק, לצמצם תנועה, לראות הצלחות עם ובלי עזרה, לייצא ולטעון גיבוי ולאפס.

הנתונים נשמרים במפתח `alma-neighborhood-v2` במכשיר ובדפדפן הנוכחיים. מהגרסה הישנה מיובאות רק העדפות העמוד והקול; ההתקדמות הישנה נשארת במפתח הקודם ואינה נמחקת. גיבויי הגרסה החדשה הם בפורמט 2. ניקוי נתוני האתר מוחק את השמירה והמטמון, לכן מומלץ לייצא גיבוי לפני מעבר למכשיר אחר. אין חשבון ילד, פרסומות, מדידה חיצונית או העלאת התקדמות לשרת.

## קבצים מרכזיים

| קובץ | תפקיד |
| --- | --- |
| `src/app.js`, `src/style.css` | מסכי השכונה, המגע והתגובות החזותיות |
| `src/neighborhood/content.js` | שש הדמויות, מאגרי המשימות והתמליל |
| `src/neighborhood/engine.js` | סינון לפי עמוד, קושי, הגרלה ושמירה |
| `src/curriculum.js` | מיפוי התוכן המקורי לחוברת |
| `src/voice-player.js`, `src/pronunciation.js` | נגן יחיד והתאמות הגייה נפרדות מהניקוד הלימודי |
| `public/assets/neighborhood/` | רקעי המשחק, איורי החפצים והבובות |
| `docs/neighborhood-art.json` | פרומפטים ורישום נכסי האיור |
| `docs/curriculum.md`, `docs/QA.md` | תכנון הלימוד ותוצאות בדיקות |

הקול הוא `he-IL-HilaNeural` בקצב ‎-12%. כדי להפיק הקראות נוספות משתמשים ב־`npm run audio` ובסביבת Python עם `edge-tts`; בזמן המשחק מושמעים קבצים מקומיים בלבד. התמליל והטקסט המותאם להגייה מתועדים ב־`docs/audio-transcript.json`. ההגייה של כל ההקלטות החדשות עדיין דורשת האזנה אנושית; בדיקות אוטומטיות אינן בודקות מבטא.

עריכות תזמון שאושרו בהאזנה נשמרות ב־`scripts/audio-edits/`: קטע המקור, הקטע המאושר, הוראות העריכה וחתימות SHA-256. הפקת הקול משתמשת בקטע המאושר במקום לסנתז אותו מחדש, ונכשלת אם הטקסט או הקובץ אינם תואמים לרישום. כך הקיצור שאושר בפתיחת ״תשובה נכונה״ נשמר גם בהפקות עתידיות. `cacheId` בתמליל מתאר את קלט הסינתזה; רשימת העריכות מתעדת את השינוי שנעשה לאחריו.

כאשר משנים נוסח שכבר פורסם, מוסיפים ב־`public/audio-aliases.json` מיפוי ממזהה ההקלטה הקודמת למזהה הנוכחי של אותו משפט. יש לעדכן גם מיפויים קיימים שמצביעים להקלטה המוחלפת. הבנייה יוצרת עותקים בכתובות הישנות ומכניסה אותם למטמון; היא נכשלת אם יעד אינו קיים באינדקס. אין להסיר כתובות ישנות רק מפני שהנוסח החדש כבר פורסם — דפים פתוחים עדיין משתמשים בהן.

גופן Heebo מופץ עם רישיון OFL ב־`public/assets/FONT-LICENSE.txt`. איורי השכונה הופקו עבור הפרויקט. צילומי החוברת משמשים למיפוי הלימוד ואינם חלק מהאתר. בדיקות התצוגה הן בדפדפן עם מידות טאבלט; לא בוצעה בדיקה על טאבלט Lenovo פיזי.
