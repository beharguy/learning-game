# גינת המילים 🌱

משחק Web ללימוד עברית בכיתה א׳, לפי סדר הנושאים והעמודים בחוברת **„קסם וחברים 2”**, עמודים 4–79. המשחק כולל 22 תחנות, תרגול ניקוד, חיבור חלקי מילים, התאמות והבנת הנקרא, גינת פרחים והקראה בעברית.

**[פתיחת המשחק 🌱](https://beharguy.github.io/learning-game/)** · [קוד המקור](https://github.com/beharguy/learning-game)

כל החוברת פתוחה כברירת מחדל. באזור ההורים אפשר לקבוע עד איזה עמוד להציג תרגילים. ההגבלה חלה על כל תרגיל בנפרד, כולל בתוך תחנה; החומר הקודם נשאר זמין לחזרה.

## מה מתרגלים

1. **ניקוד וצליל** — הסבר קצר, חיבור אות לסימן ניקוד, זיהוי הסימן ויישומו. קמץ ופתח אינם מוצגים כצלילים שונים. מעמוד 64 מצטרף שווא, ובהמשך הבחנה בניקוד בתוך מילים.
2. **מקשיבים וקוראים** — צליל פותח וסוגר, חיבור חלקים למילה, חרוזים והבנת משפטים וסיפורים. בשאלות שמיעה המילה הכתובה מוסתרת עד הצלחה או רמז.
3. **בונים מילים** — חלקי קריאה שנבחרו ידנית, כמו מָ + רָק. בהתחלה רק החלקים הדרושים; בהמשך חלק מיותר אחד. הרמז הראשון חושף את החלק הראשון, והשני את המילה.
4. **קוראים ומחברים** — שתי עמודות גלויות: צליל או מילה מול תמונה. צריך למצוא קשר, לא זוג כרטיסים זהים.

כפתור „בואי נשחק” בוחר פעילות זמינה שעוד לא הושלמה. לפני סוג משחק חדש מוצגת הדגמה חזותית בת שלושה צעדים עם קריינות; ניתן לדלג או לפתוח אותה שוב. ההוראות מוקראות אוטומטית, בלי להקריא מיד טקסט שנועד לפענוח. בשתי השאלות הראשונות יש שתי אפשרויות, והתאמות מתחילות בשני זוגות.

כל סבב קצר מתקדם מתמיכה ליישום. אחרי תשובות מופיעים הסברים, ויש הקראה ורמזים ללא הגבלת ניסיונות. סוגי המשחקים נפתחים רק כשיש עבורם תוכן מתאים לעמוד שנבחר. אין אבחון אוטומטי של רמת הקריאה; העלייה בקושי מתוכננת לפי התוכן והסבב.

## הפעלה במחשב

דרוש Node.js 18 ומעלה. אין חבילות להתקנה ואין צורך במפתח API.

```sh
npm run dev
```

פותחים `http://localhost:4173`. זו כתובת מקומית במחשב, לא קישור קבוע לטאבלט.

## בנייה ובדיקה

```sh
npm run build
npm test
npm run preview
```

`build` יוצר את `dist/`, כולל כל ההקראות, הגופנים, סמל מסך הבית ו־Service Worker לשימוש ללא רשת. `preview` מגיש את תיקיית הפריסה המקומית. יש לעצור קודם שרת אחר שמשתמש באותו פורט, או להפעיל עם `PORT=4174 npm run preview`.

כל הנכסים נכללים מקומית; בזמן המשחק אין תלות בשרת תוכן, בגופנים חיצוניים או בשירות הקראה חיצוני. בפתיחה הראשונה נחוץ חיבור לרשת. השמירה לשימוש ללא חיבור תלויה בתמיכת הדפדפן ובשטח האחסון הזמין. ניקוי נתוני האתר מוחק גם את ההתקדמות ואת המטמון.

## פריסה ב־GitHub Pages

הכתובת הקבועה של המשחק היא **https://beharguy.github.io/learning-game/**.

כל דחיפה לענף `main` מפעילה את `.github/workflows/pages.yml`: בנייה, הרצת הבדיקות ופרסום `dist/` ב־GitHub Pages. כישלון בבנייה או בבדיקות מונע פרסום של הגרסה החדשה. ניתן לעקוב אחר הפריסה ב־[GitHub Actions](https://github.com/beharguy/learning-game/actions/workflows/pages.yml) או להפעיל אותה משם מחדש באמצעות `Run workflow`.

המאגר מוגדר להשתמש ב־GitHub Actions כמקור הפרסום תחת Settings → Pages. אין צורך להעלות את `dist` למאגר, ליצור ענף `gh-pages`, או להגדיר מפתח API. לפריסה ציבורית עולים קובצי המשחק; תמונות החוברת המקוריות ונתוני ההתקדמות המקומיים אינם כלולים.

## אפשרויות אירוח נוספות

**Netlify** מתאים לגרסה הזאת: מעלים את התיקייה המוכנה ומקבלים כתובת HTTPS. אין שרת או מסד נתונים לתחזק.

1. הריצו `npm run build`.
2. היכנסו לחשבון שלכם ב־[Netlify](https://app.netlify.com/).
3. בחרו הוספת פרויקט בפריסה ידנית, או פתחו את [Netlify Drop](https://app.netlify.com/drop).
4. גררו את **התיקייה `dist`** לאזור ההעלאה. אין להעלות את תיקיית הפרויקט כולה.
5. לאחר הפריסה פתחו את כתובת ה־HTTPS שקיבלתם ושמרו אותה. אפשר לתת לאתר שם קבוע דרך הגדרות הפרויקט.
6. לעדכון המשחק, בונים שוב ומעלים את `dist` לאותו פרויקט.

אפשר גם לחבר מאגר Git: קובץ `netlify.toml` כבר מגדיר `npm run build` ואת `dist` כתיקיית הפרסום. בפריסה ידנית Netlify אינו מריץ את פקודת הבנייה, ולכן מעלים את הפלט שכבר נבנה. [תיעוד Netlify הרשמי](https://docs.netlify.com/deploy/create-deploys/).

חלופה: **Cloudflare Workers Static Assets**. קובץ `wrangler.jsonc` מוכן. לאחר התחברות לחשבון Cloudflare:

```sh
npm run build
npx wrangler deploy
```

אפשר לשנות את שם האתר בקובץ ההגדרות לפני הפריסה. [תיעוד Cloudflare הרשמי](https://developers.cloudflare.com/workers/static-assets/get-started/).

לפני מעבר לספק אירוח אחר יש לבדוק את מסלול החשבון ומגבלותיו בזמן ההרשמה; הפרויקט אינו דורש שרת או מסד נתונים.

## הוספה למסך הבית בטאבלט

לאחר הפריסה פותחים את קישור ה־HTTPS בטאבלט, וממתינים לטעינה מלאה בפעם הראשונה.

- **iPad:** ב־Safari פותחים שיתוף ← עוד, אם מופיע ← הוספה למסך הבית. אם מוצגת אפשרות „פתיחה כיישום אינטרנט”, מפעילים אותה ואז בוחרים הוספה. [הוראות Apple](https://support.apple.com/en-ke/guide/ipad/ipad8f1f7a29/ipados).
- **Android:** ב־Chrome פותחים ⋮ ← התקנה / הוספה למסך הבית, לפי האפשרות שמופיעה. [הוראות Google](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=en).

המשחק כולל סמל, שם עברי ומצב פתיחה עצמאי. נועד לפעול לאורך ולרוחב; יש להשלים בדיקה בטאבלט האמיתי של הילדה, כולל ההקראה והפתיחה מהסמל.

## הגדרות הורה והתקדמות

- כפתור **להורים** פותח תרגיל קצר (17+8). זהו מחסום מפני שינוי מקרי, לא מנגנון אבטחה.
- בוחרים עמוד 4–79. עמוד 79 משאיר את כל החוברת פתוחה.
- סיבובים שהושלמו נשמרים ב־`localStorage` במכשיר ובדפדפן הנוכחיים. סיבוב שלא הושלם מתחיל מחדש לאחר רענון.
- כל סוג משחק שהושלם בתחנה מצמיח פרח. חזרה על משחק משאירה את הפרח הקיים ומגדילה את מספר הסיבובים.
- אפשר להוריד גיבוי JSON ולטעון אותו בטאבלט. טעינת גיבוי מבקשת אישור לפני החלפת ההתקדמות המקומית.
- אין חשבונות לילדים, פרסומות, איסוף מידע אישי, שעון עצר או ענישה על טעויות.

## שינוי תוכן והקראה

ההקראה משתמשת ב־**הילה**, קול עברי נשי מסונתז (`he-IL-HilaNeural`), בקצב `-12%` שאושר בדוגמת השמיעה. ההקלטות נוצרות מראש ונכללות במשחק כ־MP3. אין קריאות לשירות הקראה בזמן משחק, ואין צורך במפתח API או ב־Python לבנייה ולפריסה רגילות.

רק לצורך יצירת הקלטות מחדש אחרי שינוי תוכן נדרשים Python וחיבור לרשת:

```sh
python3 -m venv .venv-voice
.venv-voice/bin/pip install -r requirements-voice.txt
npm run audio
npm run build
npm test
```

הייצור נעשה באמצעות [edge-tts](https://github.com/rany2/edge-tts), המשתמש בשירות ההקראה של Microsoft Edge. [רשימת הקולות של Microsoft](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=text-to-speech). הייצור שולח לשירות רק את טקסטי המשחק, ושומר מטמון כדי שאפשר יהיה להמשיך ריצה שנקטעה. הקטלוג הקיים מוחלף רק אחרי שכל ההקלטות החדשות מוכנות. אפשר להגדיר `VOICE_PYTHON` לנתיב Python חלופי עם החבילה מותקנת.

לבדיקת נוסח חדש בלי להחליף את הקטלוג הפעיל אפשר להריץ `npm run audio -- --prepare`. תמליל ההפקה שומר גם את הטקסט המקורי וגם `spokenText`: התאמות הגייה כמו „כּוֹל” מיועדות לקול בלבד, והמשחק ממשיך להציג „כָּל”. מפתח המטמון נגזר מטקסט ההקראה, כך שתיקון הגייה מייצר קובץ חדש גם אם הטקסט שעל המסך לא השתנה.

הנגן משתמש ברכיב אודיו אחד: הוראה חדשה מבטלת את הקודמת, והשתקה עוצרת גם קטעים הממתינים בתור. לחיצה מפורשת על רמקול מאפשרת לשמוע רמז גם כשקריינות אוטומטית כבויה. במקרה שהדפדפן חוסם הפעלה, מופיעה בקשה ללחוץ על הרמקול.

הקצב אושר על סמך דוגמה. הבדיקות האוטומטיות בודקות קבצים, תמליל והתנהגות נגן; הן אינן ביקורת של ההגייה בכל ההקלטות. את ההקראה וההתקנה יש לבדוק גם בטאבלט שייבחר.

גופן Heebo מופץ עם רישיון OFL ב־`public/assets/FONT-LICENSE.txt`. איורי המשחק נוצרו בקוד עבור הפרויקט. התמונות המקוריות של החוברת שימשו למיפוי בלבד ואינן חלק מהאתר.
